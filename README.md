# Univerra Simulation 🌌

A physics-accurate universe simulation with real-time visualization, supporting gravitational N-body calculations, orbital mechanics, and cosmological-scale rendering.

## Features
- N-body gravitational simulation (up to 100k bodies)
- Real-time 3D visualization via WebGL
- Configurable time scales and physical constants
- Export/import simulation states
- Built-in astronomical catalog (solar system, nearby stars)

## Quick Start
```bash
git clone https://github.com/CodexNexor/univerra-simulation.git
cd univerra-simulation
pip install -r requirements.txt
python simulate.py
```
